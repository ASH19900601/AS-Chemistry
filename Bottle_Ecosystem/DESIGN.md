# 瓶中小世界：設計方案

一個封在玻璃瓶裡的微型生態。玩家不直接操控角色，只能改變環境：調光線、調溫度、撒飼料、種水草、放小石頭、搖晃瓶子。四個顏文字小居民會依照環境自己過日子：走來走去、吃東西、睡覺，太冷的時候全部擠在一起縮成 `(;°﹏°;)`。

- 遊戲檔案：`index.html`（單一檔案，瀏覽器直接打開即可，無需安裝）
- 遊戲內文字：簡體中文
- 本文件：繁體中文

---

## 1. 核心體驗

| 項目 | 設計 |
| --- | --- |
| 類型 | 放置／觀察型小遊戲，沒有輸贏，也沒有死亡 |
| 玩家角色 | 「瓶子的主人」，只能間接影響居民 |
| 一局長度 | 不設終點；遊戲內一天 = 現實 4 分鐘 |
| 情緒目標 | 療癒、好奇，看到它們因為你的照顧而開心 |
| 核心循環 | 觀察狀態 → 調整環境 → 看居民反應 → 再調整 |

### 「不要像魚」
居民是**用腳走路**的小生物，不是在水裡游的魚：
- 每個顏文字下面畫兩隻小腳，走路時左右交替抬起，身體上下輕微彈跳。
- 它們貼著沙地和石頭表面行走（依地形高度圖），會**爬上石頭**看風景。
- 只有被搖晃或被戳時才會短暫離地，落地受重力影響，撞到玻璃會反彈。
- 瓶子是「濕地生態瓶」：沙底＋苔蘚＋水草，不是水族箱。

### 三項需求值（0–100）

| 數值 | 下降 | 回升 |
| --- | --- | --- |
| 飽腹 | 每秒 −0.55；太冷時 ×1.5；睡覺時 ×0.45 | 吃一粒飼料 +26 |

## 3. 行為狀態機

每一幀依優先順序判斷，越上面越優先：

```
在空中（被搖／被戳）  → 物理飛行，落地後若是被搖的就進入「暈」
暈乎乎               → 原地搖晃 1.8–3 秒
太冷                 → 全體（包括睡著的）醒來，擠到一起，縮成 (;°﹏°;) 發抖
睡覺                 → 直到天亮且精力夠，或白天睡飽，或餓到不行且有飼料
吃東西               → 咀嚼 2.2 秒
肚子餓（飽腹 < 62）    → 走去最近的飼料（會避開發霉的，除非餓壞了）
犯困                 → 走到最近的水草或石頭旁邊，躺下睡覺
太熱                 → 躲到高的水草下（沒有就躲石頭後面，再沒有就去遠離檯燈的左邊）
發呆 ⇄ 閒逛           → 隨機走動；25% 機會走去石頭頂上看風景；碰到別人可能打招呼
```

### 太冷時的「擠成一團」
1. 瓶內溫度跌破 12°C 時，記下所有居民的平均位置作為集合點，以及從左到右的排列順序。
2. 每隻依序排在集合點兩側，間距比身體寬度小，所以會互相擠著。
3. 縮小、抖動、吐白氣，偶爾說「好冷…」「抱紧一点」。
4. 溫度回到 13°C 以上才解散（上下限不同，避免在 12°C 附近反覆切換），並說「暖和了～」。

## 4. 環境系統

| 系統 | 規則 |
| --- | --- |
| 光照 0–100% | 滑桿直接調整，或打開「自動昼夜」：06:00 日出、18:00 日落。光越暗瓶內越暗，低於 22% 居民就想睡 |
| 溫度 | 滑桿調的是瓶底**溫控墊**的設定溫度（0–35°C）。瓶內溫度以約 7 秒的時間常數慢慢追上設定值，檯燈還會額外加溫最多 3°C |
| 氧氣 | 水草在光照下產氧（越高越健康產越多），居民耗氧（睡覺時較少），瓶塞有少量換氣 |
| 清潔度 | 水草見光會慢慢淨化；發霉飼料持續弄髒；飼料爛掉時再扣一次 |
| 環境評分 | 溫度 40% + 氧氣 30% + 清潔 30%，用來決定心情目標 |

溫度分段：

| 瓶內溫度 | 狀態 | 畫面 |
| --- | --- | --- |
| < 12°C | 太冷 | 玻璃邊緣結霜、出現霜花，溫控墊亮藍光，居民擠成一團 |
| 12–16°C | 有點涼 | 輕微霜氣 |
| 16–26°C | 舒適 | 正常 |
| 26–29°C | 有點熱 | 瓶壁凝結水珠 |
| > 29°C | 太熱 | 水珠變多、橘色暖光，居民躲陰涼 |

## 5. 玩家能做的事

| 工具 | 操作 | 效果與限制 |
| --- | --- | --- |
| 戳一戳（預設） | 點居民 | 輕輕跳一下並說話；睡著的會被戳醒、有點不爽；選中後顯示名牌 |
| 摇晃瓶子 | 按「摇一摇」、按 S，或用戳一戳工具**按住瓶子左右拖** | 依瓶子的加速度把居民和飼料甩起來，水草跟著擺動；落地會暈；20 秒內搖 3 次以上，大家會生氣 |
| 撒饲料 | 點瓶內任意位置 | 每次 3 粒，從瓶口拋落到點擊位置附近；上限 40 粒。55 秒後發霉，120 秒後爛掉 |
| 种水草 | 點瓶底 | 從小苗開始長，生長速度受光照、溫度、清潔度影響；太冷或太暗會變黃下垂；上限 8 株 |
| 放石头 | 點瓶內 | 石頭從瓶口掉下，可以疊在別的石頭上；砸到附近的居民會把它彈開（「吓一跳！」）；上限 6 塊 |

鍵盤：`1`–`4` 切換工具，`S` 搖瓶子。

```
│        （玻璃瓶畫面）           │  溫控墊滑桿＋刻度  │
│    檯燈在右上，瓶頸掛著「第N天」  │  六格讀數        │
│    牛皮紙標籤，下面是溫控墊       │ 居民             │
│                               │  表情、狀態、三條需求│
│ [戳一戳][撒饲料][种水草][放石头]  │ 瓶中日記          │
│ [摇一摇]   工具說明             │  最新事件在最上面  │
└───────────────────────────────┴──────────────────┘
```

- 狀態標籤會挑出當下最嚴重的問題（太冷 > 太熱 > 缺氧 > 很髒 > …），顏色區分正常、警告、嚴重和寒冷。
- 「瓶中日記」記錄重要事件，每類事件有冷卻時間，不會洗版。
- 點居民名單可以在瓶裡找到對應的居民。
- 窄螢幕時改為上下排列；支援深色模式；尊重「減少動態效果」設定（瓶子晃動幅度縮小）。
- 進度存在瀏覽器的 localStorage，重新打開會接著玩；「重置瓶子」需要連點兩次確認。

## 7. 技術實作

- 純 HTML + CSS + Canvas 2D + 原生 JavaScript，單一檔案，無外部函式庫（字型來自 Google Fonts，失敗時退回系統字型）。
- 世界座標固定為 600 × 660，依容器寬度與裝置像素比縮放。
- **地形**：沙面是兩個正弦波疊加；石頭是橢圓，落地後加入高度圖，居民和飼料都沿 `groundY(x)` 行走或停放。
- **玻璃內壁**：`wallAt(y)` 依瓶肩的二次曲線算出每個高度的左右邊界，用於碰撞。
- **搖晃**：瓶子的位移逐幀微分得到速度和加速度；加速度超過門檻就把居民甩起來，空中的物體再受到「反向慣性力」。
- **主迴圈**：`requestAnimationFrame`，`dt` 上限 0.05 秒；面板每 0.25 秒更新一次，存檔每 4 秒一次。

主要常數都集中在檔案開頭，方便調整難度：

| 常數 | 值 | 意義 |
| --- | --- | --- |
| `DAY_LEN` | 240 | 遊戲內一天的秒數 |
| `COLD_IN` / `COLD_OUT` | 12 / 13 | 進入／離開「太冷」的溫度 |
| `HOT_IN` / `HOT_OUT` | 29 / 28 | 進入／離開「太熱」的溫度 |
| `MOLD_AGE` / `ROT_AGE` | 55 / 120 | 飼料發霉／爛掉的秒數 |
| `MAX_PLANTS` / `MAX_STONES` / `MAX_FOOD` | 8 / 6 / 40 | 數量上限 |
| `KNOCK` | 2600 | 甩飛居民所需的加速度 |
