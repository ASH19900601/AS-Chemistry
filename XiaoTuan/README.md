# 小團的小窩

一個只有一隻小團的網頁遊戲。小團用顏文字表達心情，你可以點、長按、拖動牠，給牠東西、改天氣、一起玩小遊戲，然後觀察牠怎麼反應。

沒有關卡，也沒有「要對牠好」的規定。惹牠生氣、把牠弄哭，跟把牠哄開心一樣，都算是發現。

## 怎麼開

直接用瀏覽器打開 `index.html`。不用安裝任何東西。需要網路的只有字型（標題字型和顏文字用的幾個小字型子集），沒網路也能玩，只是顏文字的少數符號可能顯示成方塊。

想要單一檔案：

```text
python tools/build_single.py xiaotuan.html
```

## 玩法

| 操作 | 效果 |
|---|---|
| 點小團上半部 | 摸頭 |
| 點小團下半部 | 戳肚子（連點太多會被嫌） |
| 長按小團 | 抱抱，抱越久效果越不一樣 |
| 拖動小團 | 抱起來搬；左右甩會頭暈，用力甩開會丟出去 |
| 從托盤拖物品 | 放到小團、小窩或花盆上 |
| 從小團手上拖走東西 | 搶東西，牠被搶過越多次就抓越緊 |
| 拖動小窩裡的擺設 | 弄亂（或幫忙擺回去） |

面板分成四頁：

- **互動**：誇獎、貼貼、叫牠名字、安撫；嚇牠、取笑、搶東西、弄亂小窩；假裝難過、抱布偶不理牠。
- **天氣**：冷熱、風、雨（很冷時變成雪）、雷聲，以及幾個一鍵天氣。
- **小遊戲**：拉鋸、藏鈴、茶會、種芽、畫畫。
- **觀察筆記**：小團的身體與心裡狀態、目前的臉型、收集進度、還沒發現的情境提示，以及互動日誌。

## 同一個動作為什麼會有不同反應

每個反應都由三層狀態決定：

1. **身體**：體感冷熱、濕度、精神、飽足、頭暈。冷的時候抱抱很舒服，熱的時候抱太久會被推開。
2. **天氣**：下雨會讓牠躲回小窩，打雷會嚇到牠，大風會把小窩吹亂（這不是你的錯，牠不會記你的仇）。
3. **過去經歷**：信任、記仇、膽怯、委屈、得意、嘴饞、無語七種特質，加上對每樣物品的好惡和各種次數。例如：
   - 打雷時一直抱著牠，牠會越來越不怕打雷；讓牠一個人面對打雷，牠會越來越膽小。
   - 被搶過的東西，下次你的手一靠近牠就會護住。
   - 藏鈴作弊被抓到過，之後牠常常會先檢查你的手；作弊太多次，牠乾脆不跟你玩。
   - 冰塊讓牠吃過苦頭，之後你拿著冰塊靠近，牠會先躲。
   - 毯子曾讓牠暖和，冷的時候牠會主動說想要毯子。

小團說的話全部是簡體中文，按情境分開寫（例如「冷天被抱」和「熱天被抱」是不同的句庫），同一情境至少有十句，輪完一遍才會重複。臉型也會在句子前後加上口癖，例如傲嬌會補一句「…哼。」、氣鼓鼓會加「哼！」。

特質累積到一定程度，小團的**臉型**（顏文字的外框）會跟著改變，例如記仇變多會變成「氣鼓鼓」、「認真生氣」，一直被嚇會變成「膽小愛哭」，非常信任你會變成「安心滿足」。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 畫面結構 |
| `css/style.css` | 樣式與動畫 |
| `js/data.js` | 18 組臉型、物品、所有可發現的情境 |
| `js/lines.js` | 小團的台詞庫（簡體中文）：400 個情境、每個至少 10 句，用洗牌方式抽句，整輪說完才會重複 |
| `js/audio.js` | 用 WebAudio 即時合成的聲音 |
| `js/core.js` | 狀態、表情、所有互動的反應規則、小團自己的行動 |
| `js/games.js` | 拉鋸、藏鈴、茶會、畫畫、種芽 |
| `js/main.js` | 介面、拖曳輸入、天氣繪製、存檔、主迴圈 |
| `tools/build_single.py` | 合併成單一 HTML |

進度存在瀏覽器的 localStorage；在「觀察筆記」最下面可以重新開始。
